Desafio Final – Implementação do Dashboard Inteligente do

Missão

Implementar um Dashboard Gerencial totalmente funcional para o ControlTask.

O dashboard deverá consumir os dados já existentes no banco de dados da aplicação e apresentar indicadores relevantes ao usuário.

O projeto deverá manter toda a arquitetura existente:

Frontend (Streamlit)
Backend (FastAPI)
Banco SQLite
SQLAlchemy
API REST

Regras do desafio

Vocês não receberão instruções de implementação.

Será responsabilidade:

compreender a arquitetura do sistema;
identificar quais informações precisam ser obtidas do banco;
decidir quais endpoints deverão ser criados;
decidir quais alterações deverão ser realizadas no frontend;
pesquisar na documentação oficial;
utilizar IA de forma ética para acelerar o desenvolvimento.
Objetivos mínimos

O dashboard deverá apresentar, no mínimo:

Indicadores
Total de tarefas
Total de tarefas concluídas
Total de tarefas pendentes
Total de tarefas em atraso
Visualizações

Pelo menos dois gráficos, por exemplo:

tarefas por status;
tarefas por prioridade;
tarefas por mês;
tarefas por categoria (caso exista).

A escolha é da equipe.

Recursos adicionais

O dashboard deverá possuir pelo menos um recurso extra.

Exemplos:

filtro por período;
filtro por prioridade;
filtro por status;
filtro por usuário;
atualização automática;
pesquisa por palavra-chave.

A equipe pode propor outras funcionalidades.

Restrições

Não é permitido:

alterar a estrutura principal do projeto;
remover funcionalidades existentes;
modificar endpoints já utilizados pelo frontend sem justificativa.
Entregáveis

Ao final da atividade, cada equipe deverá entregar:

1. Dashboard funcionando

Executando normalmente no Streamlit.

2. Backend atualizado

Caso tenham sido criados novos endpoints.

3. API documentada

Todos os novos endpoints deverão aparecer automaticamente no Swagger.

4. Código versionado

Enviar o link do repositório GitHub atualizado.

5. Demonstração

Cada equipe terá até 10 minutos para apresentar:

quais decisões tomaram;
quais dificuldades encontraram;
quais ferramentas de IA utilizaram;
como validaram a solução.
